Design an AWS claims-processing workflow for a web application. Claims analysts upload sample documents to S3 to create a Bedrock Data Automation blueprint. A web client uploads claim documents to another S3 bucket. Use Bedrock Data Automation to extract information from the claims, SageMaker to detect possible fraud, DynamoDB to track claims-processing state, and Bedrock Nova to generate insights. Orchestrate the main workflow with Step Functions and notify the analyst by email when processing is complete.
