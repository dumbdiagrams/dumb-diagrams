Each example is one agent's unedited, one-shot answer to a prompt from the repository's prompt bank, approved after review. It keeps the rendered SVG, the `.dgm` source, the prompt, and the `requirements.json` contract the agent wrote before authoring. Review notes flag routing findings that remain. Any of them could be refined further, by asking the agent for changes or by editing in Studio.

Prompts come in three difficulties. **Easy** and **medium** prompts describe everyday architectures, and their one-shot diagrams are ready to use as they are. **Hard** prompts are dense on purpose: they are the benchmark for many interlocking relationships across regions, zones, and failure paths, so some arrow crossings remain.

## Same prompts, different models

Dumb Diagrams is not tied to one model. The validator, requirements contract, and layout engine do the checking, so any capable frontier model can produce a meaningful diagram. Runs were made with Codex and Cursor, mostly using OpenAI and Anthropic models. Each card below has a switch between two runs of all 16 prompts:

| Run | Reference | Preferences | Own contract | Routing clean |
| --- | --- | --- | --- | --- |
| GPT Luna 6 (max reasoning) | 16/16 | 16/16 | 16/16 | 11/16 |
| Claude Sonnet 5.5 (low reasoning) | 16/16 | 16/16 | 16/16 | 12/16 |

The routing findings that remain are crossings in the hard prompts, plus two backward arrows in Luna's thumbnail pipeline. Both runs are frozen as regression baselines for the engine.
