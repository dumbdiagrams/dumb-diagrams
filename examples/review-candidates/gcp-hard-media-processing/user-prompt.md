Create a GCP media processing architecture. An external media producer sends uploads through Cloud Load Balancing to a regional Cloud Run ingest service. Ingest writes the input object to Cloud Storage and publishes a job to a global Pub/Sub jobs topic. Two Compute Engine workers in separate regional subnets of one VPC consume jobs. Each worker reads input objects, writes processed objects, updates Cloud SQL job status, and publishes completion to a global Pub/Sub topic. Cloud Run notification service delivers completion to an external operations client. Jobs dead-letter to a second Pub/Sub topic. The operations client can inspect dead letters and deliberately redrive them to the jobs topic. Keep global services at project scope, regional services in their region, and show the organization/project. Do not treat a subnet as an availability zone.
