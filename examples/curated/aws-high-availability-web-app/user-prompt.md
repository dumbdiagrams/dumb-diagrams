Build a highly available AWS web application. A web client should resolve through Route 53, authenticate with Cognito, receive the frontend from CloudFront and S3, and call an API through API Gateway. Run the backend behind an Application Load Balancer in a VPC spanning two availability zones, with private application and database subnets in each zone. Each zone should run ECS and Fargate workloads and have its own DynamoDB table. Keep container images in ECR and send application and database monitoring data to CloudWatch. Keep the authentication path separate from the main request path.
