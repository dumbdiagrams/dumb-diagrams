Design an event-driven AWS order-fulfillment application. Customers should receive a storefront from CloudFront and S3, then submit orders through API Gateway to an Order service backed by DynamoDB. Publish an OrderCreated event to EventBridge and fan it out to separate inventory, payment, shipping, and customer-notification services. Run inventory and payment on Lambda, shipping on Fargate, and notifications through SNS. Keep the fulfillment services independent rather than connecting them directly to one another.
