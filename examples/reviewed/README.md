# Reviewed Studio examples

Versioned exports preserve the original SVG, its embedded `.dgm` source, and the matching prompt. `manifest.json` records provider, app version, review date, and the original SVG hash. The website copies these files without regenerating historical output.

The v0.1.0 set was generated with the local standalone CLI artifact and reviewed on 4 November 2026. Manifest review notes identify three remaining label collisions. New hard cases stay in `examples/review-candidates/` until approved.
