Create a left-to-right Azure IoT telemetry architecture. An industrial sensor fleet sends readings to Azure IoT Hub. IoT Hub routes readings to Event Hubs for processing and to a Storage Account for a raw archive. An Azure Function App consumes the event stream, normalizes readings, and writes current equipment status to Cosmos DB. An external operations dashboard reads the current status. Nest Azure resources in a subscription, region, and resource group. Add no other services and use automatic routing.
