# Changelog

All notable changes to DumbDiagrams are documented here. The project follows
the versioning policy in [docs/VERSIONING.md](./docs/VERSIONING.md).

## [1.0.0] - 2026-08-23

### Added

- Stable `.dgm` source format, deterministic AWS layout/routing, CLI, and
  desktop editor package release.
- Enterprise command-center and data-transfer architecture examples.
- Export studio with PNG, JPEG, WebP, GIF, SVG, PDF, HTML, XML, URL, JSON, and
  DGM output, full-canvas or selection scope, theme, and advanced sizing.
- CI, static deployment, and previous-tag rollback workflows.

### Changed

- Manual movement keeps authored coordinates and grows the live artboard when
  moved notes, routes, or other content extend beyond the original bounds.
- Catalog and editor controls use a desktop-first 900px minimum layout.

### Notes

- v1 does not promise a mobile editor layout.
- Provider icon redistribution remains governed by [ICON-NOTICES.md](./ICON-NOTICES.md).

## [Unreleased]

Future changes will be grouped here until the next release tag is prepared.
